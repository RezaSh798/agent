# Agent Skills Repository

مجموعه مهارت‌های توسعه‌یافته برای هوش مصنوعی کدنویسی و ابزارهای Agentic (مانند Kilo).

---

## 📦 لیست مهارت‌ها (Skills)

### 🔍 [code-review](./code-review/SKILL.md)
مهارت بررسی خودکار، دقیق و عمیق کدهای شاخه جاری در مقایسه با شاخه مرجع (`develop` یا `master`) بر اساس سه اصل:
1. **صحت عملکردی و باگ‌ها (Functionality & Correctness)**
2. **معماری تمیز و حفظ مرزبندی لایه‌ها (Clean Architecture)**
3. **کد تمیز و نگه‌داری‌پذیری (Clean Code & Readability)**

#### ویژگی‌ها:
- تولید گزارش ساختاریافته به **زبان فارسی** جهت استفاده مستقیم در کامنت Merge Request گیت‌لب.
- **تمرکز انحصاری بر تغییرات MR (Diff-Only Review)** و پرهیز از ایرادگیری به کدهای قدیمی دست‌نخورده پروژه.
- اولویت‌بندی یافته‌ها با نشانگرهای شدت خطا (🔴 بحرانی / 🟡 مهم / 🔵 کد تمیز).

---

### 🛠️ [refactor-module](./refactor-module/SKILL.md)
مهارت ریفکتورینگ عمل‌گرایانه، امن و نگه‌داری‌پذیر ماژول‌های Node.js (جاوااسکریپت و تایپ‌اسکریپت) بدون ایجاد تغییرات مخرب (Breaking Changes) یا پیچیدگی بیش از حد (Over-Engineering).

#### ویژگی‌ها:
- افزودن مستندات استاندارد JSDoc برای متدها، کلاس‌ها، پارامترها و مقادیر بازگشتی.
- بازطراحی و انطباق با اصول پنج‌گانه SOLID (شکستن توابع با SRP، استفاده از Strategy/Lookup به جای if/else برای OCP، رعایت قراردادهای LSP، اینترفیس‌های سبک با ISP، و کاهش وابستگی‌های سخت با DIP).
- نام‌گذاری شفاف متغیرها و توابع بر اساس مفاهیم دامنه.
- استفاده از Guard Clauses و Early Returns جهت کاهش پیچیدگی و تورفتگی کدهای شرطی.
- استخراج مقادیر جادویی (Magic Values) به ثابت‌های ماژول.
- بهبود تمیزی کدهای ناهمگام و ساختاردهی به خطاهای پرتاب‌شده.
- تضمین پایدار بودن قراردادهای بیرونی و عدم اعمال Breaking Changes.

### 🦊 [gitlab-issue](./gitlab-issue/SKILL.md)
مهارت تبدیل یادداشت‌ها، گزارش‌های باگ یا درخواست‌های فیچر به ایشوهای ساختاریافته و استاندارد گیت‌لب، بدون تلاش برای حل مستقیم مسئله فنی (در نقش Issue Writer / Technical PM).

#### ویژگی‌ها:
- عنوان انگلیسی شفاف با افعال استاندارد و قراردادی.
- بدنه ایشو به زبان فارسی روان و ساختاریافته (خلاصه، وضعیت فعلی، انتظار ما، پیشنهاد جهت بررسی، نکته).
- استفاده از Quick Actions گیت‌لب برای مایلسون، اساین و لیبل‌ها.
- تمرکز انحصاری بر فرموله‌کردن دقیق صورت مسئله و پرهیز از ارائه راه‌حل‌های کدی یا معماری.

### 🎯 [prompt-architect](./prompt-architect/SKILL.md)
مهارت تبدیل ایده‌ها و توضیحات خام به پرامپت‌های ساختاریافته، دقیق و آماده برای ایجنت‌های هوش مصنوعی (AI Agents).

#### ویژگی‌ها:
- تحلیل نیازمندی‌ها، بررسی ابهامات و ارائه پیشنهادات بهبود قبل از تولید نهایی.
- تولید پرامپت نهایی به زبان انگلیسی در یک کدبلاک منسجم با ساختار استاندارد (Role, Objective, Context, Technical Environment, Constraints, Evaluation Criteria, Output Format).
- اعمال اصول ضدتوهم (Anti-hallucination) و تنظیمات پیش‌فرض برای محیط‌های برنامه‌نویسی.

## 🚀 نحوه نصب و استفاده

### نصب از طریق Skills CLI:
```bash
# نصب مهارت بررسی کد
npx skills add RezaSh798/skills@code-review -g

# نصب مهارت ریفکتور ماژول
npx skills add RezaSh798/skills@refactor-module -g

# نصب مهارت ایجاد ایشو گیت‌لب
npx skills add RezaSh798/skills@gitlab-issue -g

# نصب مهارت مهندسی پرامپت ایجنت
npx skills add RezaSh798/skills@prompt-architect -g
```

### نصب دستی در مسیر مهارت‌های کلاینت:
فایل `SKILL.md` مربوط به مهارت را در مسیر مهارت‌های محلی خود (مانند `~/.agents/skills/refactor-module/SKILL.md`) کپی کنید.
